# Benchmarking U-Net Architectures for Facial Pore Segmentation

**Prepared by Yunus Emre BİLGİÇ**

## 1. Abstract

Facial pore segmentation is a small-structure semantic segmentation problem affected by limited target size, low local contrast, variable skin texture, and annotation ambiguity. This study presents a controlled benchmark of three U-Net-based architectures across three dataset scales. A ResNet34 U-Net with an ImageNet-pretrained encoder, a ResNet34 U-Net with scSE decoder attention, and a custom Attention U-Net are evaluated under the same training configuration. The benchmark uses a fixed 15-image locked test set shared across all dataset scales. The remaining development images are split into training and validation subsets using a fixed random seed, and the segmentation threshold is selected on the validation set before final evaluation on the locked test set.

The usable development pools contain 55, 157, and 1583 images for `FINAL_70`, `FINAL_173`, and `FINAL_1775`, respectively. After the fixed 20% validation split, the effective training sets contain 44, 125, and 1266 images. On the locked test set, the best observed F1/Dice scores are 0.5126 for the scSE model on `FINAL_70`, 0.5279 for the scSE model on `FINAL_173`, and 0.5319 for the custom Attention U-Net on `FINAL_1775`. The corresponding IoU values are 0.3447, 0.3586, and 0.3623. The results show that performance differences between architectures are relatively small on the largest benchmark, while model ranking changes with dataset scale. The `FINAL_1775` collection includes offline augmentation and therefore should not be interpreted as a pure dataset-size experiment. The study establishes a reproducible internal benchmark and provides a basis for future work on annotation quality, source-image lineage, repeated-seed evaluation, and hard-negative validation.

**Keywords:** facial pores, semantic segmentation, U-Net, Attention U-Net, scSE, computer vision, skin image analysis

## 2. Introduction

Automated analysis of facial pores is relevant to computer-vision-based skin image analysis and cosmetic applications. Facial pores are small structures whose apparent appearance varies with skin texture, local illumination, imaging conditions, and anatomical region. These properties make pore segmentation more difficult than segmentation of larger, well-defined objects.

Recent work has explored facial pore segmentation using weak supervision and morphology-aware deep learning. PS-Net formulates pore segmentation as a two-stage weakly supervised task using coarse labels generated by a Difference-of-Gaussian-based method and progressively refined pseudo-labels. The method also introduces high-frequency attention and a Bayesian module for pore-shape modeling [2]. Another study investigated simultaneous segmentation of wrinkles and pores using a deep-learning-based morphological feature segmentation approach [3].

The present study does not attempt to reproduce those methods. Instead, it establishes a controlled baseline using three reproducible U-Net-based architectures and three dataset scales. The main objective is to characterize the observed effect of dataset scale and model architecture under a common locked test set.

The benchmark contributions are:

1. A fixed 15-image test set shared across all reported dataset-scale experiments.
2. A direct comparison of three U-Net-based segmentation architectures under the same optimization configuration.
3. Validation-based threshold selection that does not use the locked test set.
4. A reproducible training and evaluation pipeline that records checkpoints, split manifests, thresholds, training history, and test metrics.

## 3. Related Work

### 3.1 U-Net-based segmentation

U-Net is an encoder-decoder architecture with skip connections designed for biomedical image segmentation [1]. Its ability to combine high-level semantic features with higher-resolution encoder features makes it suitable for small-object segmentation tasks. The current benchmark uses a ResNet34 U-Net as its baseline.

### 3.2 Attention-based segmentation

Attention U-Net introduced attention gates that learn to suppress irrelevant regions in skip connections while emphasizing features useful for segmentation [4]. The custom model evaluated in this study follows the general attention-gated U-Net design and applies additive attention gates at the decoder skip connections.

### 3.3 Facial pore segmentation

PS-Net is a recent facial pore segmentation framework using weak supervision, coarse labels, progressively updated pseudo-labels, high-frequency attention, and Bayesian modeling [2]. Yoon et al. investigated simultaneous segmentation of pores and wrinkles using morphological facial-skin features [3]. These studies motivate the use of high-resolution encoder-decoder architectures for facial pore analysis, while the present work focuses on a simpler fully supervised benchmark.

## 4. Method

### 4.1 Problem formulation

Pore segmentation is formulated as binary semantic segmentation. For an RGB input image \(I\), the model predicts a single-channel probability map \(P\), which is thresholded to obtain a binary pore mask. Ground-truth masks contain background pixels and pixels belonging to the pore class.

### 4.2 Architectures

Three architectures are evaluated:

**ResNet34 U-Net (baseline).** A U-Net with a ResNet34 encoder initialized using ImageNet weights.

**ResNet34 U-Net with scSE.** The same ResNet34 U-Net backbone with scSE decoder attention.

**Custom Attention U-Net.** A five-level encoder-decoder model trained from scratch with additive attention gates on decoder skip connections.

The parameter counts are 24,436,369 for the baseline, 24,550,360 for the scSE model, and 31,395,053 for the custom Attention U-Net.

### 4.3 Mask generation and data preparation

The source datasets were exported in YOLO polygon format. Class-0 polygon annotations corresponding to pores were converted to binary PNG masks. Polygon coordinates were mapped from normalized YOLO coordinates to image pixels. Image-mask pairs were checked before training so that missing masks were not silently interpreted as negative examples.

### 4.4 Test-set isolation

A single 15-image test set was retained and copied into all three finalized benchmark datasets. Hash-based duplicate screening was used during dataset curation to detect test images that also appeared in training data. The implemented hash is an 8×8 grayscale average hash represented by 64 binary comparisons. This procedure is treated as a duplicate-screening mechanism rather than a mathematical proof of zero leakage.

### 4.5 Dataset scales

The dataset identifiers correspond to the source collections used in the project. The finalized benchmark development pools contain 55, 157, and 1583 usable images for `FINAL_70`, `FINAL_173`, and `FINAL_1775`, respectively. Each dataset also contains the same 15 locked test images.

The development pools are split using `random_state=42` and a validation ratio of 0.20. The resulting training/validation/test counts are:

| Dataset | Development pool | Training | Validation | Locked test |
|---|---:|---:|---:|---:|
| FINAL_70 | 55 | 44 | 11 | 15 |
| FINAL_173 | 157 | 125 | 32 | 15 |
| FINAL_1775 | 1583 | 1266 | 317 | 15 |

The `FINAL_1775` collection includes offline geometric and photometric augmentation. Therefore, the comparison across dataset scales reflects both the number of available images and differences in dataset composition/augmentation history.

### 4.6 Training configuration

All final benchmark experiments use:

| Setting | Value |
|---|---:|
| Input resolution | 512 × 512 |
| Batch size | 4 |
| Epochs | 40 |
| Optimizer | AdamW |
| Learning rate | 1 × 10⁻⁴ |
| Weight decay | 1 × 10⁻⁵ |
| Loss | BCE + Dice |
| Validation ratio | 20% |
| Random seed | 42 |
| Training augmentation | None in the final benchmark |
| Threshold search | 0.05–0.95, step 0.01 |

No online random augmentation is applied during the final benchmark. The offline augmented images are already part of the `FINAL_1775` source collection.

The ResNet34 models use ImageNet-pretrained encoders. The custom Attention U-Net is trained from scratch.

### 4.7 Threshold selection

The best validation checkpoint is selected using the minimum validation loss. After loading the best checkpoint, prediction probabilities are evaluated on the validation subset at thresholds from 0.05 to 0.95 in increments of 0.01. The threshold with the highest validation F1/Dice is selected and then fixed for the locked-test evaluation.

### 4.8 Evaluation metrics

Pixel-level precision, recall, F1/Dice, and IoU are computed from global true-positive, false-positive, and false-negative pixel counts:

\[
Precision = \frac{TP}{TP+FP}
\]

\[
Recall = \frac{TP}{TP+FN}
\]

\[
F1 = \frac{2TP}{2TP+FP+FN}
\]

\[
IoU = \frac{TP}{TP+FP+FN}
\]

These are global pixel-level metrics aggregated over the 15-image locked test set.

## 5. Experiments

Nine final benchmark experiments are performed: three dataset scales × three model architectures. The same locked 15-image test set is used in every experiment. The test set is not used for parameter updates, checkpoint selection, or threshold selection.

The final benchmark differs from earlier prototype experiments in the project. Earlier K-fold and pseudo-labeling notebooks were development experiments and were not used to generate the final results reported in Table 1. They are therefore excluded from the main experimental claims.

## 6. Results

### 6.1 Locked-test results

| Dataset | Model | Threshold | F1 / Dice | IoU | Precision | Recall |
|---|---|---:|---:|---:|---:|---:|
| FINAL_70 | ResNet34 U-Net | 0.25 | 0.5008 | 0.3341 | 0.5108 | 0.4912 |
| FINAL_70 | ResNet34 U-Net + scSE | 0.27 | 0.5126 | 0.3447 | 0.4883 | 0.5396 |
| FINAL_70 | Custom Attention U-Net | 0.32 | 0.3706 | 0.2274 | 0.3446 | 0.4007 |
| FINAL_173 | ResNet34 U-Net | 0.21 | 0.5130 | 0.3450 | 0.4705 | 0.5639 |
| FINAL_173 | ResNet34 U-Net + scSE | 0.32 | 0.5279 | 0.3586 | 0.5223 | 0.5336 |
| FINAL_173 | Custom Attention U-Net | 0.20 | 0.5048 | 0.3376 | 0.4795 | 0.5328 |
| FINAL_1775 | ResNet34 U-Net | 0.31 | 0.5305 | 0.3610 | 0.5265 | 0.5345 |
| FINAL_1775 | ResNet34 U-Net + scSE | 0.41 | 0.5207 | 0.3520 | 0.4967 | 0.5471 |
| FINAL_1775 | Custom Attention U-Net | 0.22 | 0.5319 | 0.3623 | 0.5294 | 0.5344 |

On `FINAL_70`, the scSE model has the highest observed test F1/Dice among the three evaluated architectures. On `FINAL_173`, the scSE model again has the highest observed test F1/Dice. On `FINAL_1775`, the custom Attention U-Net has the highest observed F1/Dice (0.5319), although the difference from the baseline (0.5305) is small.

The architecture ranking is therefore not constant across dataset scales. The results do not support a universal performance ordering of the three architectures.

### 6.2 Validation-to-test gap

For `FINAL_1775`, the validation F1 values at the selected thresholds were approximately 0.8701 for the baseline, 0.8762 for scSE, and 0.8363 for the custom Attention U-Net. The corresponding locked-test F1 values were 0.5305, 0.5207, and 0.5319. The gap indicates that validation performance is substantially higher than locked-test performance for these experiments.

Possible contributors include the small test set, differences between development and test distributions, annotation variability, and correlations within the augmented dataset. The current study does not isolate the contribution of each factor.

## 7. Qualitative Evaluation

The benchmark stores, for each model and dataset, the original test image, ground-truth mask, predicted mask, prediction overlay, and a TP/FP/FN error map. A probability heatmap is also generated for post-hoc inspection.

These visualizations are used to inspect whether metric differences correspond to visible changes in localization and segmentation. Because the available ground truth does not contain separate labels for specific hard-negative structures, the current study does not quantify false positives by biological subtype.

## 8. Discussion

The results show that the standard ResNet34 U-Net and its scSE variant perform similarly across the three dataset scales, while the custom Attention U-Net improves markedly between the smallest and largest development pools. However, the difference among the three models on `FINAL_1775` is small. Therefore, the benchmark does not establish that additional attention mechanisms are consistently beneficial.

The dataset-scale comparison is also not a pure sample-count experiment. `FINAL_1775` includes offline augmentation, so its performance reflects both a larger number of training examples and a different data-generation process. A controlled augmentation study would be required to isolate those effects.

The large validation-to-test gap is another important observation. It indicates that a high validation F1 should not be treated as a direct estimate of generalization performance for these data. The fixed locked test set is useful for cross-experiment comparison, but its size of 15 images is too small for a precise estimate of population-level performance.

The current pixel-level evaluation also measures agreement with the available annotations rather than biological correctness independent of those annotations. This is especially relevant for pore segmentation because small boundary differences can affect F1/Dice and IoU even when the predicted region is visually close to the labeled structure.

## 9. Limitations

1. The locked test set contains only 15 images.
2. The `FINAL_1775` collection contains offline augmentation and therefore cannot be interpreted as a pure increase in independent source images.
3. Annotation quality has not been independently assessed by multiple expert annotators.
4. Inter-rater agreement has not been measured.
5. No external dataset was used for validation of cross-source generalization.
6. The current binary annotation scheme does not explicitly separate pores from all visually similar structures.
7. A 64-bit average-hash screening procedure was used for duplicate detection, but no method can establish universal zero leakage from hashing alone.

## 10. Future Work

Future experiments should focus on three areas: source-lineage control for augmented images, repeated-seed evaluation, and annotation-quality auditing.

A repeated-seed benchmark can report mean ± standard deviation across independent training runs. A source-lineage manifest can keep all variants of one original image in the same partition. A manually reviewed evaluation subset can be used to distinguish model errors from annotation omissions or ambiguous structures.

Additional work can investigate hard-negative classes, but this requires explicit and consistently applied annotations for those structures before a quantitative classification or rejection experiment can be reported.

## 11. Conclusion

This study provides a controlled internal benchmark for facial pore segmentation using three U-Net-based architectures and three dataset scales. The same locked 15-image test set is used throughout, while threshold selection is performed only on the validation subset.

The observed test F1/Dice scores range from 0.3706 to 0.5319 across the nine reported experiments. The scSE architecture has the highest observed F1 on the 70-image and 173-image benchmark collections, while the custom Attention U-Net has the highest observed F1 on the 1775-source collection. Because the ranking changes across dataset scales and the difference on `FINAL_1775` is small, the current results do not establish a single universally superior architecture.

The benchmark is intended as a reproducible baseline for the next stage of the project, with emphasis on annotation quality, source-image lineage, repeated-seed evaluation, and external validation.
